# Simple Interest Calculator

A simple command-line script to calculate simple interest given principal, annual rate of interest, and time period in years.

## Formula
Simple Interest = (P * T * R) / 100

- **P** = Principal amount
- **T** = Time period in years
- **R** = Annual rate of interest

## Usage
Run the shell script:
```bash
bash simple-interest.sh
```
