# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Fork the Repository:** Create your own fork of the project.
2. **Clone the Fork:** Clone your fork to your local machine.
   ```bash
   git clone https://github.com/<your-username>/github-final-project.git
   ```
3. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make Your Changes:** Test and ensure your modifications are clean and well-documented.
5. **Commit Your Changes:**
   ```bash
   git commit -m "Add descriptive commit message"
   ```
6. **Push to Your Branch:**
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Open a Pull Request:** Submit a PR with details of the proposed changes.
